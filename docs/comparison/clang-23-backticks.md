## Compile cost

No instruction counter: `kernel.perf_event_paranoid` blocks user-space
counts on this host, so these are times, not counts. `sudo sysctl
-w kernel.perf_event_paranoid=2` would make this axis deterministic
too.

Best of 5 runs, pinned to one core, the variants interleaved --
phase breakdowns included, so no column comes from a single compile.
The control is the pipe source compiled a second time under another
name: it is the same work, so its distance from the pipe column is what
this machine contributes on its own. A pipe-to-backtick difference no
larger than that is measurement, not code.

The `machine` column is the pipe-to-control gap. A pipe-to-backtick
gap counts only where it is twice that and at least 0.10s; anything
smaller this host cannot resolve. Read the machine column first: if it
is not near zero, the box was busy and the row says nothing.

Larger than the machine gap, and so worth reading: triples.
Compare each against its two `headers` columns before crediting it
to the spelling -- the backtick sources include one header more.
