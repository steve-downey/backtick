* The pitch in one line

C++ spells a handful of binary operations infix and lets you overload them.
Everything else is a call.

#+begin_src c++
a `plus` b              // plus(a, b)
a `std::min` b          // std::min(a, b)
m `at` k                // at(m, k)
u `dot` v               // dot(u, v)
x `approx_equal` y      // approx_equal(x, y)
#+end_src

=x `f` y= *is* =f(x, y)=. That is the entire semantic.

#+begin_notes
Haskell programmers recognise this immediately: =`div`=, =`mod`=, =`elem`=.
#+end_notes

* It desugars to a call

The operator lowers to a call expression in the front end, before overload
resolution runs. Not a macro, not a new AST category with its own type rules.

So the feature inherits, for free and correctly:

#+ATTR_REVEAL: :frag (appear)
- overload resolution and ADL
- templates and dependent lookup
- =constexpr= evaluation
- codegen, debug info, and the ABI

* Precedence

Highest-precedence *binary* operator: tighter than =*=, looser than
unary/prefix. Operands are /cast-expressions/, so the rule is symmetric:

#+begin_src c++
-a `f` -b               // f(-a, -b)
#+end_src

The slot between the backticks is an /assignment-expression/.

* The same-delimiter problem

Open and close are the same token, so the operator interpretation has to be
suppressed inside the slot — Clang's =BacktickIsOperator=, modelled on
=GreaterThanIsOperator=; GCC's =backtick_is_operator_p=, modelled on
=greater_than_is_operator_p=.

Bare nesting is token-identical to a left-associative chain, so it is accepted
rather than diagnosed. To nest, parenthesize the slot.

* Two compilers

| Track       | Branch           | Base                  |
|-------------+------------------+-----------------------|
| Clang       | =backtick-23=    | =release/23.x=        |
| Clang       | =backtick-trunk= | =upstream/main=       |
| GCC         | =backtick=       | trunk                 |

Everything sits behind =-fbacktick=. A default build is byte-identical to
upstream.
